# 开发计划

本文档记录 `pdfget-refine` 的后续开发计划、待决策项和发布注意事项。

## 1. 当前状态

- 分发包名已更新为 `pdfget-refine`。
- 版本号已切换为 `1.0.0`，作为 fork 后的首个独立发行版本。
- README、CHANGELOG、LICENSE 已补充仓库继承关系与署名说明。
- 当前控制台命令仍保留为 `pdfget`，尚未迁移为 `pdfget-refine`。
- 目前该仓库主要供个人使用，暂不发布在 PyPI

## 2. 待办项

### 2.1 CLI 命名统一

目标：在不影响现有用户脚本的前提下，评估是否将控制台命令从 `pdfget` 迁移为 `pdfget-refine`。

建议步骤：

1. 先确认是否存在依赖 `pdfget` 命令名的现有文档、脚本和自动化任务。
2. 如果要迁移，先同步更新 README、用户指南和发布说明。
3. 再修改 `pyproject.toml` 中的 `project.scripts`，并补充回归测试，验证命令入口可用。
4. 在发布前保留一段兼容说明，避免用户升级后找不到旧命令。

当前结论：暂不修改控制台命令名，先继续沿用 `pdfget`。

## 3. 后续发布建议

- 每次涉及命令入口、包名或作者信息变更时，先更新文档再发版。
- 如果未来切换到 `pdfget-refine` 命令，应在一个独立版本中完成，并在更新日志中明确标注迁移说明。
- 若要对外发布 PyPI 包，建议在发布说明中同时给出上游仓库链接和 fork 起点 commit。
